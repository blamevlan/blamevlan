# blamevlan

I mostly do network and infrastructure stuff.

Linux, Proxmox, OPNsense, Ansible, Python.

I automate things when doing them by hand gets annoying.

Linux where possible, Windows when necessary, Apple when someone else is paying.

---

## Projects

- [**netblame**](https://github.com/blamevlan/netblame) — network diagnostics for DNS, ports, SSL, ping, traceroute and local network scanning.
- [**depcheck**](https://github.com/blamevlan/depcheck) — checks what would happen before removing packages on Fedora/RHEL.
- [**carekit**](https://github.com/blamevlan/carekit) — Fedora setup, system checks and local backups in one small tool.
